---
description: Generate comprehensive QA test cases for a page or feature
argument-hint: [url-or-description]
---

Run TestersAI in Test Case Generation mode. Load the testersai skill first.

If $ARGUMENTS contains a URL, navigate to it and analyze the page to generate comprehensive test cases covering functional, UI/UX, performance, security, and accessibility testing.

If $ARGUMENTS contains a feature description, generate test cases based on that description.

If no arguments are provided, ask the user what they want test cases for.

Output organized test cases with priority levels, steps, expected results, and test data.
