---
description: Get diverse user persona feedback on a page or design
argument-hint: [url-or-description]
---

Run TestersAI in Persona Feedback mode. Load the testersai skill first.

If $ARGUMENTS contains a URL, navigate to it and capture a screenshot. Then simulate diverse user perspectives from the persona database, generating feedback from users of different ages, backgrounds, and tech proficiency levels.

If $ARGUMENTS contains a description or the user uploaded a screenshot, use that as the basis for persona analysis.

If no arguments are provided, ask the user what they want persona feedback on.

Generate a visual HTML report with star ratings, profile images, and detailed first-person quotes from each persona.
