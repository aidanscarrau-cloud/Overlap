Run Testers.AI in Generate Test Steps mode. Load the testersai skill first.

If $ARGUMENTS contains a URL, navigate to it and generate test steps. If a prompt follows the URL, focus on that scenario. If no URL, ask the user.

Generate executable test case JSON that can be replayed with /play.
